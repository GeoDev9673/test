Техническое задание
Интерактивный сайт PARALIFE — MEMORY CINEMA
1. Общая задача
На основе уже созданного в AI Studio сайта необходимо собрать первую рабочую версию интерактивного сайта PARALIFE.
Это не должен быть обычный лендинг, состоящий из вертикальных блоков.
Пользователь должен чувствовать, что он:
1.	видит здание Memory Cinema с улицы;
2.	приближается к нему;
3.	входит внутрь;
4.	проходит через фойе;
5.	оказывается в длинном коридоре;
6.	самостоятельно выбирает зал;
7.	входит в мир отдельного героя;
8.	в конце может попасть в главный зал с клипом Stealing Time.
Основная задача первого этапа — создать правильную структуру сайта, переходы между пространствами и систему замены контента.
Финальные фотографии, видео и звуки будут предоставлены позже.

2. Важный технический принцип
На первом этапе не требуется создавать полноценную настоящую 3D-модель кинотеатра.
Эффект движения внутри пространства можно сделать с помощью:
•	полноэкранных видео;
•	изображений высокого разрешения;
•	фиксированных сцен;
•	CSS-трансформаций;
•	увеличения масштаба изображения или видео;
•	движения фона по оси X и Y;
•	sticky-секций;
•	анимации, зависящей от скролла;
•	плавных затемнений между сценами.
Пользователь должен визуально чувствовать движение камеры вперёд, хотя технически это может быть заранее подготовленный ролик или анимация масштаба.
Не нужно использовать тяжёлые 3D-движки, если тот же эффект можно получить проще.

3. Структура сайта
Сцена 1. Вступление
При первом открытии сайта появляется короткая заставка:
PARALIFE PRESENTS
Заставка должна быть минимальной и длиться примерно 1–2 секунды.
После неё плавно появляется основной экран с Memory Cinema.
Не нужно одновременно показывать:
•	большое меню;
•	длинный текст;
•	описание проекта;
•	много кнопок;
•	дополнительные информационные блоки.

Сцена 2. Фасад Memory Cinema
На первом экране должен находиться полноэкранный видеоролик кинотеатра.
Видео занимает всю ширину и высоту браузера:
width: 100vw
height: 100vh
object-fit: cover
В дальнейшем мы предоставим ролик, в котором камера показывает Memory Cinema с разных сторон.
Пока финального ролика нет, нужно использовать временное видео или изображение-заглушку.
Поведение сцены
Когда пользователь начинает скроллить:
•	страница не должна сразу уходить вертикально вниз;
•	камера должна визуально приближаться к входу в кинотеатр;
•	здание постепенно становится крупнее;
•	фон может немного смещаться;
•	вход должен приближаться к центру экрана;
•	в конце происходит затемнение;
•	после затемнения пользователь оказывается внутри кинотеатра.
Не должно быть ощущения перехода к следующему обычному блоку сайта.
Должно быть ощущение, что камера физически вошла в здание.
Дополнительная реакция на мышь
На компьютере можно добавить очень небольшое движение камеры за курсором:
•	лёгкое смещение;
•	небольшой поворот перспективы;
•	движение с задержкой и инерцией.
Эффект должен быть слабым. Это не должна быть игровая 3D-сцена.

Сцена 3. Фойе и касса
После входа пользователь видит фойе старого кинотеатра.
В кадре может находиться:
•	касса;
•	стены;
•	старые афиши;
•	двери;
•	лампы;
•	начало коридора.
При дальнейшем скролле пользователь не опускается к следующему блоку.
Камера начинает двигаться вперёд вдоль кассы и постепенно выходит в большой коридор.
Важно
Фойе не должно быть перегружено:
•	большими текстовыми окнами;
•	колонками с информацией;
•	карточками;
•	меню справа;
•	отдельными информационными блоками.
Интерфейс должен оставаться почти незаметным.

Сцена 4. Коридор с залами
Коридор является основной навигацией сайта.
Пользователь должен чувствовать, что находится внутри кинотеатра и может самостоятельно выбрать, в какой зал войти.
По обе стороны коридора располагаются настоящие двери залов.
Примерный порядок:
Слева — OPUS
Справа — RYAZ

Слева — GLAM
Справа — CHASE

Слева — CHRISTMAS
В конце или отдельно — STEALING TIME
Расположение можно скорректировать под композицию коридора.
Названия залов
Названия не должны отображаться в виде отдельных карточек или всплывающих окон.
Название должно быть частью двери:
•	табличкой над дверью;
•	надписью на двери;
•	названием кинозала;
•	встроенным текстом рядом с дверным проёмом.
Взаимодействие с дверью
При наведении курсора на дверь:
•	название становится немного ярче;
•	дверь может слегка приоткрыться;
•	изнутри появляется свет;
•	может появиться тихий звук, связанный с героем.
При клике пользователь входит в выбранный зал.
Пользователь не обязан проходить залы по порядку.
Он сам выбирает нужную дверь.
Движение по коридору
Скролл должен визуально двигать камеру в глубину коридора.
При этом двери постепенно приближаются, проходят рядом с пользователем и остаются доступными для выбора.
Не нужно делать обычную вертикальную страницу, где двери расположены одна под другой.

4. Залы героев
Необходимо создать пять залов:
1.	OPUS;
2.	RYAZ;
3.	GLAM;
4.	CHASE;
5.	CHRISTMAS.
Каждый зал должен иметь одинаковую техническую структуру, но разный визуальный и звуковой контент.
Это позволит не создавать пять разных сайтов, а использовать один универсальный компонент зала.

Структура каждого зала
Первый экран
После входа в зал на весь экран запускается короткий ролик о герое.
Видео должно занимать весь экран:
width: 100vw
height: 100vh
object-fit: cover
Не нужно помещать видео:
•	в маленькое окно;
•	в рамку;
•	в карточку;
•	в экран ноутбука;
•	в отдельный блок с большими полями.
Дальнейший скролл
При скролле после ролика пользователь может увидеть:
•	имя героя;
•	одну короткую фразу;
•	краткое описание;
•	одну или две цитаты;
•	несколько дополнительных кадров или деталей.
Текста должно быть мало.
Не требуется делать длинную биографию героя.
Пример структуры:
OPUS

HE WRITES DOWN
WHAT STRANGERS
LEAVE BEHIND.

Короткое описание в 2–4 строки.
Навигация внутри зала
В каждом зале должны находиться:
•	кнопка или ссылка «BACK TO CORRIDOR»;
•	кнопка включения и выключения звука;
•	возможность вернуться в коридор без перезагрузки всего сайта.
Желательно, чтобы после возвращения пользователь оказался примерно в том месте коридора, откуда вошёл в зал.

5. Главный зал Stealing Time
Последний зал отличается от залов героев.
При входе пользователь сначала видит настоящий большой кинозал:
•	ряды кресел;
•	тёмное пространство;
•	большой экран в конце зала.
На экране уже может идти клип Stealing Time или его заставка.
Поведение при скролле
При скролле пользователь не должен уходить вниз под кинозал.
Камера начинает двигаться вперёд между креслами и приближаться к киноэкрану.
Последовательность:
1.	пользователь входит в кинозал;
2.	видит кресла и экран вдалеке;
3.	начинает скроллить;
4.	камера движется к экрану;
5.	кресла постепенно уходят за пределы кадра;
6.	экран становится всё больше;
7.	в конце видео занимает весь экран браузера;
8.	начинается или продолжается полный клип Stealing Time.
Когда экран приблизился, видео должно стать практически полноэкранным.
Не нужно помещать клип в маленький прямоугольник внутри страницы.
Загрузка видео
Полный клип не нужно загружать сразу при открытии главной страницы.
Он должен загружаться только при приближении к главному залу или при входе в него. Это необходимо для быстрой загрузки сайта.

6. Subscribe
Форма подписки должна быть доступна пользователю, даже если он не прошёл весь сайт до конца.
Поэтому лучше использовать два способа входа в форму.
Первый способ — постоянная небольшая ссылка
В верхней части сайта должна находиться аккуратная ссылка:
LEAVE YOUR SIGNAL
Она может находиться рядом с логотипом или кнопкой звука.
Ссылка не должна выглядеть как большая рекламная кнопка.
При клике открывается небольшое полноэкранное или боковое окно поверх текущей сцены.
Пользователь не переходит на другую страницу.
После закрытия формы он возвращается в то же место сайта.
Второй способ — внутри истории
После главного зала или рядом с выходом из кинотеатра можно повторно показать форму как часть пространства:
•	старый билет;
•	книга посетителей;
•	карточка у кассы;
•	приглашение на следующий сеанс.
Текст:
LEAVE YOUR SIGNAL

THE NEXT ROOM
WILL OPEN SOON.

LEAVE YOUR EMAIL
TO RECEIVE THE INVITATION.
Поля:
Email
SEND THE SIGNAL
После отправки:
YOUR SIGNAL
HAS BEEN RECEIVED.
Что сделать на первом этапе
На первом этапе необходимо:
•	создать внешний вид формы;
•	сделать проверку правильности email;
•	сделать состояние успешной отправки;
•	подготовить функцию для подключения сервиса подписки.
Подключение конкретной базы подписчиков или email-сервиса можно выполнить отдельно, когда будет выбран сервис.

7. Фото, видео и звуки должны легко заменяться
Не нужно жёстко прописывать каждый файл внутри разных компонентов.
Все медиафайлы должны храниться в понятных папках.
Пример:
/public/media/exterior/
/public/media/lobby/
/public/media/corridor/
/public/media/halls/opus/
/public/media/halls/ryaz/
/public/media/halls/glam/
/public/media/halls/chase/
/public/media/halls/christmas/
/public/media/main-auditorium/
/public/audio/
Пример названий файлов:
exterior-video.mp4
exterior-poster.jpg
lobby-video.mp4
corridor-video.mp4

opus-video.mp4
opus-poster.jpg
opus-audio.mp3

ryaz-video.mp4
ryaz-poster.jpg
ryaz-audio.mp3
Контент залов желательно вынести в один файл настроек.
Например:
export const halls = [
  {
    slug: "opus",
    title: "OPUS",
    video: "/media/halls/opus/opus-video.mp4",
    poster: "/media/halls/opus/opus-poster.jpg",
    audio: "/audio/opus-audio.mp3",
    quote: "HE WRITES DOWN WHAT STRANGERS LEAVE BEHIND.",
    description: "Temporary description."
  }
];
Когда будут готовы финальные материалы, мы должны иметь возможность заменить путь к файлу, не переделывая весь сайт.

8. Звук
Да, звук может и должен меняться в каждом зале.
Но звук всегда должен быть выключен при первом открытии сайта.
Пользователь сам нажимает:
SOUND ON
После этого сайт может воспроизводить звук.
Логика звука
•	на улице — городской фоновый шум;
•	в фойе — тихая атмосфера старого кинотеатра;
•	в коридоре — общий фоновый звук;
•	в зале Opus — отдельная звуковая атмосфера Opus;
•	в зале Ryaz — отдельная атмосфера Ryaz;
•	аналогично для остальных героев;
•	в главном зале — звук клипа Stealing Time.
При переходе между сценами звук должен плавно затихать и заменяться следующим.
Не должно быть резкого обрыва или одновременного воспроизведения нескольких аудиодорожек.
Нужен один общий контроллер звука для всего сайта.

9. Минимальный интерфейс
На экране постоянно могут находиться только:
•	логотип PARALIFE;
•	SOUND ON / OFF;
•	LEAVE YOUR SIGNAL;
•	при необходимости — BACK TO CORRIDOR.
Не должно быть:
•	большого правого меню;
•	постоянно открытой боковой панели;
•	большого количества кнопок;
•	информационных карточек;
•	квадратной сетки;
•	колонок с текстом;
•	стандартных блоков музыкального лендинга;
•	большого футера.

10. Шрифт
Существующий шрифт необходимо заменить.
Шрифт должен выглядеть:
•	современно;
•	дерзко;
•	редакционно;
•	минималистично;
•	премиально;
•	не слишком декоративно.
В качестве основы можно использовать стиль, близкий к PP Mori.
Если оригинальный PP Mori отсутствует, необходимо использовать доступный современный grotesk с похожим характером.
Шрифты должны быть заданы глобально, а не отдельно в каждом компоненте.
Нужно настроить:
•	основной шрифт интерфейса;
•	размеры заголовков;
•	межбуквенные расстояния;
•	высоту строки;
•	мобильные размеры текста.

11. Предлагаемая структура компонентов
Названия могут отличаться, но сайт желательно разделить примерно так:
CinemaIntro
ExteriorScene
EntranceTransition
LobbyScene
CorridorScene
CinemaDoor
CharacterHall
MainAuditorium
SubscribeOverlay
SoundControl
MainMenu
Для всех пяти героев используется один компонент:
CharacterHall
Разные данные передаются через файл настроек.
Не нужно копировать один и тот же код пять раз.

12. Этапы работы
Этап 1. Разобраться в существующем коде
Необходимо:
•	запустить проект локально;
•	проверить структуру папок;
•	понять, какие компоненты уже есть;
•	не переписывать всё с нуля без необходимости;
•	удалить или отключить ненужные блоки текущего лендинга;
•	сохранить рабочую версию перед изменениями.
Результат этапа: понятно, какие части существующего кода можно оставить.

Этап 2. Собрать простую рабочую структуру
Пока без финальных медиа необходимо сделать:
•	вступление;
•	фасад;
•	переход внутрь;
•	фойе;
•	коридор;
•	шесть дверей;
•	переходы в пять залов героев;
•	переход в зал Stealing Time;
•	возврат в коридор;
•	форму подписки.
Для временного контента можно использовать изображения, цветные заглушки и короткие тестовые видео.
Результат этапа: весь путь пользователя работает, даже если дизайн пока не финальный.

Этап 3. Настроить скролл и движение камеры
Необходимо сделать:
•	приближение к кинотеатру;
•	проход через вход;
•	движение вдоль кассы;
•	движение в глубину коридора;
•	приближение к экрану в главном зале;
•	плавные затемнения;
•	отсутствие резких переходов.
Результат этапа: сайт ощущается как одно непрерывное пространство.

Этап 4. Создать универсальный зал героя
Сначала необходимо полностью сделать один тестовый зал, например OPUS.
После утверждения структуры этот же компонент используется для:
•	Ryaz;
•	Glam;
•	Chase;
•	Christmas.
Результат этапа: пять залов работают на одной технической системе.

Этап 5. Подключить систему медиа и звука
Необходимо:
•	разложить файлы по папкам;
•	вынести пути в конфигурацию;
•	добавить постеры для видео;
•	добавить ленивую загрузку;
•	создать общий контроллер звука;
•	добавить плавную смену аудио.

Этап 6. Адаптация под телефон
На мобильном устройстве нужно сохранить тот же путь:
фасад → вход → фойе → коридор → залы
Но эффекты можно упростить:
•	уменьшить движение камеры;
•	отключить реакцию на курсор;
•	сделать двери крупнее;
•	использовать вертикальный свайп;
•	уменьшить количество параллакса;
•	проверить отсутствие горизонтальной прокрутки.

Этап 7. Оптимизация
Необходимо:
•	не загружать все видео одновременно;
•	использовать poster для каждого видео;
•	загружать зал только при входе;
•	загружать полный клип только перед главным залом;
•	сжимать изображения;
•	предусмотреть WebM и MP4;
•	проверить сайт на компьютере и телефоне;
•	добавить режим reduced motion.

13. Что пока не входит в первую версию
На первом этапе не требуется:
•	создавать финальные ролики;
•	создавать фотографии героев;
•	строить полноценный 3D-кинотеатр;
•	создавать сложную игровую механику;
•	добавлять личный кабинет;
•	создавать Personal Memory Space;
•	делать виртуальные концерты;
•	создавать CMS;
•	загружать большое количество текста;
•	придумывать новые истории героев;
•	подключать сложную базу данных.
Сейчас необходимо создать фундамент, в который позже будут вставлены готовые материалы.

14. Критерии готовности первой версии
Первая версия считается рабочей, если:
1.	При открытии появляется PARALIFE PRESENTS.
2.	После заставки запускается полноэкранная сцена Memory Cinema.
3.	При скролле пользователь визуально приближается к зданию.
4.	Переход внутрь происходит плавно.
5.	Пользователь проходит через фойе к коридору.
6.	В коридоре находятся двери Opus, Ryaz, Glam, Chase, Christmas и Stealing Time.
7.	Каждую дверь можно выбрать самостоятельно.
8.	Каждый зал открывается.
9.	В каждом зале есть полноэкранное тестовое видео или заглушка.
10.	Из каждого зала можно вернуться в коридор.
11.	В зале Stealing Time камера приближается к киноэкрану.
12.	Форма подписки открывается без ухода с сайта.
13.	Все медиафайлы можно заменить через понятную папку или файл настроек.
14.	Звук по умолчанию выключен.
15.	Сайт работает на компьютере и телефоне.
16.	На сайте нет лишних карточек, боковых блоков и перегруженного текста.
17.	Переходы между сценами плавные, а не резкие.

15. Главный приоритет
Сначала необходимо сделать не идеальный дизайн, а правильную механику:
пользователь увидел кинотеатр
→ приблизился
→ вошёл
→ прошёл в коридор
→ выбрал дверь
→ вошёл в зал
→ вернулся
→ продолжил путь
Когда этот путь будет работать, можно заменять заглушки на финальные изображения, ролики, звуки и тексты.
Не нужно начинать с мелких визуальных деталей, пока не работает вся основная структура сайта.
